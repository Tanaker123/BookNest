# BookNest
Android-приложение для управления семейной библиотекой. Позволяет вести каталог авторов и книг, отслеживать местонахождение книжных экземпляров, фиксировать прогресс чтения, сохранять оценки и рецензии, а также составлять список книг для будущих покупок.

## Стек
- Kotlin, Jetpack Compose
- Coroutines
- ViewModel + StateFlow
- Room
- Coil

## Планируемый объем работы
### 1. Управление авторами
- Просмотр списка авторов, добавленных в приложение.
- Добавление нового автора с указанием полного имени.
- Возможность прикрепить фотографию автора.
- Просмотр страницы автора со списком его книг.
- Редактирование информации об авторе.
На главном экране для каждого автора отображается количество книг, связанных с ним.

### 2. Управление книгами
- Просмотр информации о книге.
- Добавление книги с указанием названия и автора.
- Возможность прикрепить обложку книги.
- Указание жанра и года издания при наличии соотвествующей информации.
- Выбор статуса: "В планах", "Читаю", "Прочитано" или "Не дочитала".
- Указание члена семьи, у которого хранится книга.
- Добавление оценки, личной рецензии и дополнительных заметок.
- Редактирование информации о книге.
- Удаление книги из каталога.
Для книг, запланированных к приобретению, должна быть возможность отметить отсутсвие физического экземляра и не указывать место хранения.

### 3. Поиск и фильтрация
- Поиск книг по названию.
- Поиск авторов по имени.
- Просмотр всех книг независимо от автора.
- Фильтрация по статусу чтения и покупки.
- Фильтрация по жанру.
- Фильтрация по члену семьи, у которого хранится книга.
- Возможность сбросить применённые фильтры.

## Пользовательский интерфейс
- Главный экран со списком авторов.
- Экран со списком книг выбранного автора.
- Экран со списком всех книг.
- Экран подробной информации о книге.
- Формы добавления и редактирования авторов и книг.

## Основные пользовательские сценарии
### 1. Добавление автора
1. Пользователь открывает главный экран.
2. Нажимает кнопку добавления автора.
3. Вводит полное имя автора.
4. При необходимости выбирает фотографию из галереи.
5. Сохраняет данные.
6. Новый автор появляется в общем списке.

### 2. Просмотр авторов и его книг
1. Пользователь открывает главный экран.
2. Приложение отображает список авторов:  ФИО, фотографию и количество книг.
3. Пользователь нажимает на нужного автора.
4. Приложение открывает экран с подробной информацией об авторе и списком его книг.

### 3. Редактирование автора
1. Пользователь открывает карточку автора.
2. Нажимает кнопку "Редактировать".
3. Приложение открывает форму с текущими данными автора: ФИО, фотографией и другими предусмотренными полями. 
4. Пользователь изменяет необходимые данные и сохраняет изменения.

### 4. Добавление книги в библиотеку
1. Пользователь выбирает автора и открывает форму добавления книги.
2. Вводит название книги и указывает необходимые характеристики.
3. При необходимости добавляет обложку. 
4. Выбирает статус чтения ("Читаю", "Прочитано" или "Не дочитала").
5. Указывает члена семьи, у которого хранится книга.
6. При необходимости добавляет оценку, рецензии и заметки.
7. Сохраняет книгу

### 5. Добавление книги в список будущих покупок
1. Пользователь открывает форму добавления книги.
2. Указывает название и автора.
3. Выбирает статус "В планах".
4. При необходимости добавляет обложку и заметки.
5. Сохраняет запись.

### 6. Просмотр и редактирование книги
1. Пользователь открывает список книг автора или общий каталог.
2. Выбирает нужную книгу. 
3. Просматривает её характеристики, статус, место хранения, оценку и рецензию.
4. При необходимости изменяет данные и сохраняет изменения.

### 7. Поиск и фильтрация
1. Пользователь открывает общий каталог.
2. Вводит название книги или имя автора либо выбирает необходимые фильтры.
3. Приложение отображает записи, соответствующие заданным условиям. 
4. При необходимости пользователь сбрасывает фильтры.

### 8. Сохранение данных между запусками
1. Пользователь добавляет авторов и книги.
2. Закрывает приложение.
3. Повторно запсукает приложение.
4. Открывает каталог и карточки ранее добавленных книг. 

## Критерии готовности проекта
Проект считается готовым, если выполнены следующие условия:
- Реализовано локальное хранение данных с помощью Room.
- Пользователь может добавлять, просматривать, редактировать авторов.
- Пользователь может добавлять, просматривать, редактировать и удалять книги.
- Книги связаны с соотвествующими авторами.
- Реализованы статусы "В планах", "Читаю", "Прочитано" или "Не дочитала".
- Для книг можно указывать место хранения, оценку и рецензию. 
- Реализован выбор фотографий авторов и обложек книг из галереи.
- Изображения сохраняются и корректно отображаются после повторного запуска приложения.
- Количество книг каждого автора автоматически обновляется при добавлении и удалении книг.
- Работают поиск и фильтрация по предусмотренным параметрам.
- Данные сохраняются между запусками приложения.
- Основные функции доступны без подключения к интернету. 

Интеграция с внешним книжным каталогом может быть реализована в дальнейшем как дополнительная функция, но к критерию готовности проекта не относится.
